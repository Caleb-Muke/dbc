Guide de Démarrage Rapide

  1. Ouvrez le site: Cliquez sur "Aller au Site" ci-dessus
  2. Explorez les sections: Accueil, Structure, Événements, Contact
  3. Remplissez le formulaire: Adhérez au parti DBC
  4. Gérez les adhésions: Ouvrez le Panneau Admin pour voir les données
  5. Exportez les données: Utilisez le bouton "Exporter CSV" dans l'admin
